# Учёт времени по PERCo

Первая версия сервиса работает в браузере: Excel-файлы остаются на устройстве пользователя. Статические файлы приложения не содержат персональных данных из образца выгрузки.

## Запуск на Windows

Дважды щёлкните `Запустить сервис.cmd`. Откроется браузер по адресу `http://localhost:8765/`. Окно запуска оставьте открытым на время работы; закрытие окна остановит сервис. Для запуска нужен Python 3, который установлен на исходном компьютере. Сервис слушает только `127.0.0.1` и не доступен другим компьютерам сети.

При повторном открытии страницы нужно снова выбрать Excel-файлы. В репозиторий следует добавлять только исходный код; рабочие Excel-выгрузки и готовые отчёты исключены через `.gitignore`.

## Что делает

- Принимает несколько однотипных `.xlsx` выгрузок PERCo и удаляет точные повторы событий.
- Позволяет выбрать диапазон дат, группировку по дням, неделям или месяцам и сортировку по фамилии или дате.
- Показывает каждую закрытую пару входа и выхода через проходную и полное время присутствия на заводе. Повторные входы до окончания смены относятся к ней же; промежутки вне завода не включаются и отмечаются в графе «График». Смена через полночь целиком относится к дате её начала; цеха входят в это время.
- Отмечает поздний вход и ранний выход относительно порогов: дневная смена — вход до 06:50, выход после 19:10; ночная — вход до 18:50, выход после 07:10 следующего дня. Если за смену было несколько проходов, сравниваются первый вход и последний выход.
- Считает время в цехах, столовой и на общей территории; несогласованные интервалы оставляет нераспределёнными.
- Показывает расчётный остаток часового обеда в цехе отдельно, не приписывая его конкретному цеху.
- Показывает хронологию по сотрудникам и календарным дням с объединёнными ячейками и номерами строк исходных Excel-файлов.
- Скачивает один цветной Excel-файл с листами «Завод», «Цеха» и «Хронология»: зелёный — по графику и время в цехах, жёлтый — выход с завода или обед, красный — отклонение от графика или неясное время, синий — проходная и время вне цехов.

## Ограничения этой версии

Перезагрузка страницы требует вновь выбрать Excel-файлы. Выгрузка, которая обрывается посреди смены, создаёт открытый вход и не даёт рассчитать время до выхода. При отсутствии отметки о переходе время по конкретным цехам остаётся в графе «Неясно». Длительность посещения столовой определяется только по согласованным входу и выходу. Отметки по графику показывают факты прохода; причина отклонения определяется человеком.

## Проверка

`node test.mjs` проверяет интервал через полночь и границу месяца, обнаружение пропущенного перехода, ручную коррекцию и часовую поправку на обед. Интерфейс проверен на предоставленном XLSX-файле без включения этого файла в исходный код.
