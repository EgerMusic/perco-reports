# Учёт времени по PERCo

Первая версия сервиса работает в браузере: Excel-файлы остаются на устройстве пользователя. Статические файлы приложения не содержат персональных данных из образца выгрузки.

## Запуск на Windows

Дважды щёлкните `Запустить сервис.cmd`. Откроется браузер по адресу `http://localhost:8765/`. Окно запуска оставьте открытым на время работы; закрытие окна остановит сервис. Для запуска нужен Python 3, который установлен на исходном компьютере. Сервис слушает только `127.0.0.1` и не доступен другим компьютерам сети.

При повторном открытии страницы нужно снова выбрать Excel-файлы. Ручные исправления сохраняются в локальном хранилище этого браузера. Для дальнейшей публикации на GitHub в репозиторий следует добавлять только исходный код; рабочие Excel-выгрузки и готовые отчёты исключены через `.gitignore`.

## Что делает

- Принимает несколько однотипных `.xlsx` выгрузок PERCo и удаляет точные повторы событий.
- Позволяет выбрать диапазон дат, группировку по дням, неделям или месяцам и сортировку по фамилии или дате.
- Показывает каждую закрытую пару входа и выхода через проходную и время присутствия на заводе; цеха входят в это время.
- Считает время в цехах, столовой и на общей территории; несогласованные интервалы оставляет нераспределёнными.
- Даёт указать время пропущенного перехода или исключить неверную отметку с причиной и возможностью отмены.
- Показывает расчётный остаток часового обеда в цехе отдельно, не приписывая его конкретному цеху.
- Показывает хронологию интервалов и ссылки на номера строк исходных Excel-файлов для несостыковок.
- Скачивает один Excel-файл с листами «Завод», «Цеха», «Хронология» и «Несостыковки».

## Ограничения этой версии

Исправления хранятся в браузере, где их внесли. У нескольких пользователей пока нет общей базы исправлений. Перезагрузка страницы требует вновь выбрать Excel-файлы. Выгрузка, которая обрывается посреди смены, создаёт открытый вход и не даёт рассчитать время до выхода. При отсутствии отметки о переходе время по конкретным цехам требует ручного уточнения. Длительность посещения столовой определяется только по согласованным входу и выходу. Порогов опоздания и раннего ухода в отчёте нет по согласованному упрощению.

## Проверка

`node test.mjs` проверяет интервал через полночь и границу месяца, обнаружение пропущенного перехода, ручную коррекцию и часовую поправку на обед. Интерфейс проверен на предоставленном XLSX-файле без включения этого файла в исходный код.
