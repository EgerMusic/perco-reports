# Учёт времени по PERCo

Сервис сравнивает месячный план смен с фактическими проходами в цех. Excel-файлы обрабатываются в браузере и остаются на устройстве пользователя.

## Запуск на Windows

Дважды щёлкните `Запустить сервис.cmd`. Откроется браузер по адресу `http://localhost:8765/`. Окно запуска оставьте открытым на время работы; закрытие окна остановит сервис. Для запуска нужен Python 3, который установлен на исходном компьютере. Сервис слушает только `127.0.0.1` и не доступен другим компьютерам сети.

Выбранные Excel-файлы автоматически сохраняются в IndexedDB этого браузера. При повторном открытии сервис восстанавливает копии исходных файлов, заново читает их и строит отчёт. Период, сортировка, группировка и выбранная таблица также сохраняются. О сохранении сообщает строка под кнопками загрузки. «Удалить сохранённые файлы» удаляет копии и очищает отчёт.

Хранилище относится к конкретному браузеру, профилю, устройству и адресу сайта. Данные localhost и GitHub Pages хранятся отдельно. В другом браузере/на другом компьютере файлы нужно выбрать отдельно. Очистка данных сайта удаляет копии; приватный режим не обеспечивает хранение после закрытия. Если сохранение невозможно, сообщение об этом остаётся на странице, а текущими отчётами можно пользоваться. При конфликте двух вкладок требуется обновить страницу, чтобы не перезаписать чужие изменения.

В репозиторий следует добавлять только исходный код; рабочие Excel-выгрузки и готовые отчёты исключены через `.gitignore`.

## Загрузка

1. «Проходы PERCo»: одна или несколько подробных XLSX-выгрузок с колонками «Выход из» и «Вход в».
2. «Месячный график»: XLSX с месяцем и годом в заголовке, ФИО, табельными номерами и днями месяца. Сохраняйте исходные цвета ячеек.
3. «Сводка с графиками K»: XLSX-отчёт «Время присутствия» с колонкой «График работы». Сводка задаёт шаблон часов; она не заменяет подробные события.

Файлы можно выбирать в любом порядке. Читаются все листы с подходящими заголовками; исходные листы и номера строк сохраняются. Поддерживаются текстовые даты и числовые даты Excel, включая систему дат 1904 года. Новый месяц, год, число сотрудников, порядок строк и положение подписанных столбцов не привязаны к образцу ноября. После загрузки графика период ограничивается пересечением месяца и дат проходов, если проходы уже загружены. Сортировка доступна по фамилии и дате. Группировка день/неделя/месяц применяется к таблице цехов; план/факт и хронология всегда показывают отдельные смены.

## Правила расчёта

- Сопоставление использует табельный номер без пробелов и ведущих нулей, фамилию и инициалы. Подразделение дополнительно проверяется при выборе шаблона K. Повторы номера в плане отмечаются комментарием.
- Для двенадцатичасовых смен белое «11» в плане означает 07:00–19:00, серое «11» — 19:00–07:00. Ночная смена целиком относится к дате начала. Это согласованная расшифровка данного шаблона графика.
- Шаблоны K 07:00–16:00 и 08:00–17:00 остаются дневными. Они не превращаются в ночные по цвету ячейки или фактическим проходам. Противоречия с месячным планом показываются в комментарии.
- Приход и уход сравниваются с планом по первому подтверждённому входу и последнему выходу из любого цеха, с точностью до минуты. Прежние пороги проходной 06:50/19:10 не применяются.
- «От входа до выхода» — промежуток между этими отметками, включая перерывы. «В цехах» — сумма только согласованных интервалов в цехах. Пропуски переходов не заполняются предположениями.
- Повторные посещения в пределах смены объединяются. Время вне завода исключается из подтверждённых интервалов и отмечается комментарием.
- Два самостоятельных выхода на работу за календарные сутки показываются разными строками. Если один из них не предусмотрен планом, он отмечается как выход вне графика.
- Один час обеда учитывается один раз на смену. Подтверждённое время столовой уменьшает расчётную часть обеда в цехе. Обед в цехе не приписывается конкретному участку.
- Плановые смены без отметок показываются отдельно. При неполном покрытии периода или отсутствии сотрудника в подробных проходах используется статус «Недостаточно данных». Ранний выход не выводится для незаконченной выгрузки.
- Неизвестные цвета, неподдерживаемые часы K, значения «7»/«8» без часов начала и конца и другие противоречия требуют уточнения и помечаются в строке.

Выгрузка содержит цветные листы «План и факт», «Цеха» и «Хронология». Зелёный означает соответствие графику, красный — отклонение, жёлтый — данные для уточнения, серый — отсутствие плана или полного факта. Номера исходных строк включены в Excel; на странице они также видны в подсказках к плану и отметкам входа/выхода.

## Ограничения этой версии

Общей базы исправлений нет. Неучтённые проходы и причины отклонений требуют проверки человеком. Длинные интервалы свыше 20 часов помечаются для уточнения; отдельный интервал такой длины не считается подтверждённым временем в цехе. Для ночных смен на границе периода нужна выгрузка с соседними днями. Разрывы между файлами не считаются покрытым периодом. Если дни окрашены условным форматированием, нужно сохранить цвета обычной заливкой. Книга с несколькими месяцами, точный повтор сотрудника в плане, ошибки Excel или формулы без сохранённого результата отклоняются с пояснением. Новые обозначения смен и иной смысл цветов требуют настройки. Данные сотрудников и отчёты не включаются в репозиторий.

## Проверка

`node test.mjs` проверяет базовый разбор событий. `node test-plan.mjs` проверяет план/факт, границы цеха, ночную смену через границу месяца, повторные входы, один обед, неполные данные и дневные шаблоны K. `node test-robustness.mjs` проверяет две смены за сутки, неизвестные коды, разрыв покрытия файлов, некорректное время, пробелы заголовков, новый месяц/год, високосный февраль и дубли плана. Реальные XLSX-файлы не хранятся в тестах или репозитории.
